# Qwen3.5-9B 高数助手 · SFT 数据集 v3 构建要求

> **版本**：v1（2026-10-16）
> **依据**：5k/20k 同分布实验（隔离集 113↔113 零增益）+ 300 题隔离集逐题失败分析
> **用途**：交付数据生成器/标注流程执行；生成产物由 `qlora_math/train.py` 消费训练

---

## 1. 为什么需要 v3（背景）

现有数据（template_family ≈ `high_math_v1`，5k/20k 同源）已耗尽收益：

| 实验证据 | 结论 |
|---|---|
| 5k vs 20k（同分布） | 隔离集 37.7% vs 37.7%，逐题翻转 18↔18 → **数据量 ×4 零增益** |
| 失败模式 | 难度 2 失败 = 计算滑移；难度 3 失败 = 新结构方法错误；9 类题型 0/10~11 |
| 成功面 | 输出协议（格式）100% 稳定；分布内模板 ≈75%+ |

**v3 要解决的三个瓶颈**：
1. **模板族多样性**——只看参数变化教不会新结构（9 类零分题型的核心问题）；
2. **难度覆盖**——训练数据只有难度 1–2，评测含难度 3（48.9% vs 18.8% 的落差）；
3. **计算可靠性**——答案中缺少"分步 + 验算"示范，模型学会了跳步算错。

| 项目 | 要求 |

## 3. 重点题型新结构详单（核心章节）

**原则：改变题目/函数结构，而不是仅换数字；每个新结构 ≥ 200–400 条不同参数组合。**

### 3.1 零分题型（最高优先级，合计 ~6.5–8k）

| 题型 category | 20k 成绩 | 新结构要求 | 建议量 |
|---|---|---|---|
| `implicit_derivative_quadratic_curve` | 0/11 | 曲线类型扩展：`xy=K`、`x²y+xy²=K`、`e^{xy}+…`、`sin(xy)+x²y`、`x³y` 高次交叉项；**必须含乘积法则交叉项**（实测错点：把 d(6xy)/dx 写成 `6y(y'+1)`）；可加"求 y''"层 | 800–1000 |
| `derivative_exponential_trigonometric` | 0/11 | 多因子乘积 `e^{ax}(b·sin cx + d·cos cx)`、`x^n·e^{ax}·sin(bx)`；链式嵌套 `e^{sin x}`、`ln(cos x)`；至少 3 类结构轮换 | 800–1000 |
| `integral_symmetry` | 0/10 | 被积函数升级：三角奇偶组合（`sin³x·cos²x`、`x·cos x`）、指数对称项、多项+三角混合；**答案要求：奇部=0 与偶部 2∫₀ᵃ 之后逐项积分的每一步分开写**（实测推理对、终值算错） | 800–1000 |
| `partial_derivatives_polynomial` | 0/10 | 更高次/交叉项（`x²y³`、`3x⁴y`）、分数/负系数、三元偏导、二阶偏导 f_xy；**答案要求：先写偏导表达式，再分两个小步代点** | 700–900 |
| `double_integral_rectangle` | 0/10 | 被积函数含指数/三角分量（`e^{x+y}`、`x·sin y`）、交换积分顺序、混构多项式；答案逐次代入上下限 | 700–900 |
| `tangent_plane` | 0/10 | `z=f(x,y)` 升级：`e^{xy}`、`ln(x+y)`、`xy²`；可选隐曲面 `F(x,y,z)=0` 基础版 | 700–900 |
| `ode_first_order_linear_constant` | 0/10 | `y′+ky=b(x)`（b 为常数/指数/多项式，积分因子法）；初值点多样；**答案要求：通解 → 代入初值 → 解常数 三步显式拆开**（实测结构对、代入算错） | 700–900 |
| `limit_factor_cancellation` | 0/11 | 因式结构升级：`x³−a³`、立方和/差、高次约分；新增有理化型 `(√(x+a)−√b)/(x−c)`；答案显式写出分解/有理化过程 | 700–900 |
| `integral_definite_polynomial` | 0/10 | 系数/次数复杂化（含分数系数、合并同类项多步化简）；答案：积分后**逐项代入分开写** | 600–800 |

### 3.2 弱项题型（20k 成绩 ≤30%，合计 ~4–5k）

| 题型 | 20k 成绩 | 新结构要求 | 建议量 |
|---|---|---|---|
| `integral_by_parts_x_exp` | 0/10 | `∫x^n e^{ax} dx`（n=1,2 二次分部）、`∫x·e^{ax}·sin(bx) dx`（入门级）；答案完成"分部→再分部→整理"完整链 | 600–800 |
| `limit_logarithmic_standard` | 1/11 | `ln(1+ax)/x`、`ln(1+ax)/ln(1+bx)`、`(a^x−1)/x` 变体 | 500–700 |
| `directional_derivative` | 1/10 | 梯度含 ln/exp/三角；单位化步骤显式化；可选三元 | 500–700 |
| `total_differential` | 1/10 | f 含 `e^{xy}`、`ln(xy)`、`x·sin y`；代点计算拆步 | 500–700 |
| `geometric_series_sum` | 1/10 | 起点变体（n=0 起）、公比负/分数、`r^{2n}` 变形 | 500–700 |
| `limit_trigonometric_standard` | 2/11 | `sin(ax)/tan(bx)`、`(1−cos ax)/x²`、多因子比值 | 500–700 |
| `limit_exponential_standard` | 3/11 | `(e^{ax}−1)/x`、`(1+ax)^{b/x}`、`(a^x−1)/(b^x−1)` | 500–700 |
| `tangent_line_polynomial` | 3/11 | 切点计算复杂化（高次/分式多项式）、可结合隐函数求导 | 500–700 |

### 3.3 次级与强项

- **次级**（36–50%）：`derivative_polynomial_at_point`、`p_series_convergence`、`improper_integral_exponential`——各补 300–500 条变体即可；
- **强项**（≥70%：数列极限、单调区间、弧长、收敛半径、代换积分、二阶常系数 ODE、不定积分等）——**仅 A 组存量复用，不投新工作量**。

## 4. 难度体系

- d1/d2：沿用现有刻度；
- **d3 判定规则**：≥3 个独立知识点，或明确的组合链。示例：
  1. 隐函数求导 → 写切线方程（组合）
  2. 换元积分 → 定值代入（链）
  3. 对称性判定 → 逐项积分（多步计算）
  4. 一阶线性 ODE：通解 → 初值 → 验算（三步）
- d3 占比目标：**全场约 25%**（C 组全部 + B 组约 1/3）。

---

## 5. 答案书写规范（直接塑形模型行为，务必执行）

1. **推导分步**：think 内每个等式/操作单独成步；**禁止把 2 步以上算术压成一句话**（现有数据存在"一步算完"，模型已模仿此不良习惯）；
2. **验算段**：位于 `</think>` 之前，以"**验算：**"开头，按题型选择：
   - 导数/切线 → 代回原函数/曲线方程；
   - 不定积分 → 对结果求导回验；
   - 定积分 → 用区间估计/奇偶性复核符号量级；
   - ODE → 代入原微分方程；
   - 极限 → 特殊值或量级估计。
3. 最终答案统一 `\boxed{}`；`canonical_answer` 必须与 reference_solution 中 boxed 内容一致（程序校验）；
4. LaTeX 规范：多项式**降幂排列**、分数统一 `\frac`、避免与 canonical 的纯格式差异（减少严格匹配误杀）。

## 6. 隔离审计与质检

1. **模板族标注**：每条必须带 `template_family` + `structure_signature`；
2. **预留 eval_v3**：~300 题（重点题型每类 2–3 个**专用结构模板**，绝不进入训练）→ 作为 v3 后的**新主指标**；
3. **跨集去重**：与 5k、20k、现有 300 题（isolated_v2）按题面 SHA-256 全量查重并记录；
4. **重要说明**：v3 训练数据**允许**包含与 isolated_v2 相似的结构（这正是要教的能力）；因此原 300 题基准继续保留作"历史对比基准"，但要清楚其分数会因相似性上升——**新主指标必须是 eval_v3**；
5. 生成后必过质检（输出 `validation_report_v3.json`）：
   - JSON 可解析 / 角色序 system→user→assistant / id 唯一 / SHA 去重；
   - `<think>…</think>` + `\boxed{}` 完整；canonical 能程序验算的抽样回验 ≥5%；
   - 难度、配比、题型分布统计。

## 8. 流程与验收目标

**流程**：先出 **v3-lite（8–10k）** → 训练（约 40 分钟）→ eval_v3 + 300 题双基准评测 → 方向确认后放量。

**验收目标**（建议值，以实测为准）：

| 指标 | 现状（20k） | v3 目标 |
|---|---|---|
| eval_v3 等价正确率（主指标） | —（新集） | ≥ 55% |
| 300 题基准（历史可比） | 37.7% | ≥ 50%（含相似结构，会偏高） |
| 难度 3（300 题） | 17–19% | ≥ 35% |
| 强项不退化（100% 类题型） | 100% | 保持 ≥ 90% |

**通过后接 GRPO**：奖励 = `canonical_answer` + math_verify（基建已就绪）；prompt 从 v3 训练题抽样并给弱项加权。

## 附录 A：三个代表性新结构示例

**A1 · 隐函数（乘积法则交叉项）**
> 曲线 $x^2y+xy^2=30$ 经过点 $(2,3)$，求该点切线斜率。
> 要点：两边求导得 $2xy+x^2y'+y^2+2xyy'=0$——**两个交叉项都带 y′**；整理 $y'=-\frac{2xy+y^2}{x^2+2xy}$，代点 $\Rightarrow -\frac{21}{16}$。
> 教学价值：直接针对"d(6xy) 写成 6y(y'+1)"的错点。

**A2 · 对称性积分（分步终值）**
> 求 $\int_{-2}^{2}(3x^5+x^2\cos x+x^4+4)\,dx$。
> 要点：$3x^5$、$x^2\cos x$ 为奇 → 0；偶部 $2\int_0^2(x^4+4)dx=2\left(\frac{32}{5}+8\right)=\frac{144}{5}$（逐项算、分开写）。
> 教学价值：修复"对称性判断对、终值算错"。

**A3 · 一阶线性 ODE（三步 + 验算）**
> 解 $y'-3y=6,\ y(0)=5$。
> 要点：通解 $y=Ce^{3x}-2$；$C=7$；**验算：** 代回 $y'-3y=21e^{3x}-(21e^{3x}-6)=6$ ✓，$y(0)=7-2=5$ ✓。
> 教学价值：示范"代入初值 + 回代验算"。
