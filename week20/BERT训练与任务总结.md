## BERT 简介

**BERT** = Bidirectional Encoder Representations from Transformers (双向编码器)

### 核心特点
- ✅ **双向理解**: 同时看前文和后文
- ✅ **预训练+微调**: 先学通用语言知识,再适配具体任务
- ✅ **只做理解**: 擅长分类、抽取,不擅长生成
- ✅ **换头即用**: 不同任务只需换不同的输出头

---

## BERT 预训练

### 训练目标
让 BERT 学会理解语言的通用知识(语法、语义、常识等)

### 两个预训练任务(同时进行)

BERT 使用**一个编码器**同时完成**两个任务**,通过不同的输出位置实现:
- **[CLS] 位置** → NSP 任务(句子级别)
- **[MASK] 位置** → MLM 任务(词级别)

---

#### 任务1: MLM (掩码语言模型) - 填空题

**原理**: 随机遮盖 15% 的词,让模型预测被遮盖的词

**示例**:
```
原始句子: 我 喜欢 吃 苹果
遮盖后:   我 喜欢 [MASK] 苹果
模型预测: [MASK] = "吃"
```

**详细过程**:
```
输入: 我 喜欢 [MASK] 苹果
  ↓
BERT 双向编码 (每个词都能看到前后文)
  ↓
[MASK] 位置的预测概率:
  - "吃":  0.65  ← 最高
  - "喝":  0.15
  - "买":  0.10
  - 其他:  0.10
  ↓
损失计算: -log(0.65) = 0.43
```

**为什么有效?**
- 强迫模型理解上下文
- 学会词与词之间的关系
- 掌握语法和语义知识

---

#### 任务2: NSP (下一句预测) - 判断题

**原理**: 判断两个句子是否连续

**示例**:
```
正例 (IsNext):
句子A: 我喜欢吃苹果
句子B: 苹果很甜
标签: 1 (是下一句)

负例 (NotNext):
句子A: 我喜欢吃苹果
句子B: 今天天气很好
标签: 0 (不是下一句)
```

**详细过程**:
```
输入: [CLS] 我喜欢吃苹果 [SEP] 苹果很甜 [SEP]
  ↓
BERT 编码
  ↓
取 [CLS] 位置的向量 (代表整体语义)
  ↓
二分类器预测:
  - 是下一句: 0.85  ← 最高
  - 不是:     0.15
  ↓
损失计算: -log(0.85) = 0.16
```

**为什么有效?**
- 学习句子间的逻辑关系
- 理解篇章结构
- 提升长文本理解能力

---

### 完整训练示例(MLM + NSP 同时进行)

#### 步骤1: 准备训练样本

**原始文本:**
```
"我喜欢吃苹果。苹果很甜。"
```

**构造训练样本:**
```
句子A: "我喜欢吃苹果"
句子B: "苹果很甜"  (真实的下一句)
NSP标签: 1 (IsNext)
```

#### 步骤2: 对输入进行掩码

```
原始输入: [CLS] 我 喜欢 吃 苹果 [SEP] 苹果 很 甜 [SEP]
掩码后:   [CLS] 我 [MASK] 吃 苹果 [SEP] [MASK] 很 甜 [SEP]
                    ↑                      ↑
                 位置2                   位置6
              MLM标签:"喜欢"          MLM标签:"苹果"
```

#### 步骤3: BERT 编码(共享编码器)

```
输入: [CLS] 我 [MASK] 吃 苹果 [SEP] [MASK] 很 甜 [SEP]
  ↓
BERT 编码器(12层Transformer)
  ↓
输出每个位置的向量(768维):
  位置0 [CLS]:  用于 NSP 预测 ←┐
  位置1 "我":   参与编码        │
  位置2 [MASK]: 用于 MLM 预测 ←┤ 同一个编码器
  位置3 "吃":   参与编码        │ 同时输出
  ...                          │
  位置6 [MASK]: 用于 MLM 预测 ←┘
  ...
```

#### 步骤4: 两个任务头分别预测

```
┌─────────────────────────────────┐
│     BERT 编码器输出              │
└─────────────────────────────────┘
            ↓
    ┌───────┴────────┐
    ↓                ↓
[CLS]向量        [MASK]位置向量
    ↓                ↓
┌────────┐      ┌────────┐
│NSP预测头│      │MLM预测头│
└────────┘      └────────┘
    ↓                ↓
是下一句?         预测被遮盖的词
(0.85)           位置2:"喜欢"(0.70)
                 位置6:"苹果"(0.80)
    ↓                ↓
NSP损失          MLM损失
-log(0.85)       [-log(0.70)-log(0.80)]/2
= 0.16           = 0.27
```

#### 步骤5: 联合训练

```
总损失 = MLM损失 + NSP损失
      = 0.27 + 0.16
      = 0.43
  ↓
反向传播
  ↓
同时更新:
  - BERT 编码器(共享,受两个任务影响)
  - MLM 预测头
  - NSP 预测头
```

---

### 预训练总结

```
BERT 总损失 = MLM 损失 + NSP 损失
```

**关键特点**:
- ✅ **共享编码器**: 一个 BERT 同时服务两个任务
- ✅ **不同输出**: [CLS] 做 NSP,[MASK] 做 MLM
- ✅ **联合优化**: 两个任务的梯度共同优化编码器
- ✅ **互补学习**: 词级理解 + 句级理解 = 全面的语言能力

**训练数据**: 大规模无标注文本 (如维基百科、书籍等)  
**训练时间**: 数天到数周 (使用多张 GPU)  
**训练一次**: 得到通用的 BERT 模型,可用于各种下游任务

---

### 现代实践的变化
重要说明：现代的 BERT 类模型（如 RoBERTa）已经不使用 NSP 任务了！
原因：
研究发现 NSP 任务对模型性能提升有限
只用 MLM 也能达到很好的效果
简化了训练流程
所以：
原始 BERT (2018)：MLM + NSP
RoBERTa (2019)：只用 MLM，去掉 NSP
现代实践：大多只用 MLM

## BERT 微调任务

### 核心思想
```
预训练好的 BERT (通用语言理解能力)
        ↓
    换个任务头
        ↓
在特定任务数据上微调
        ↓
    完成特定任务
```

---

### 任务1: 文本分类

**应用场景**: 情感分析、新闻分类、垃圾邮件检测等

#### 示例: 情感分类

**任务**: 判断评论是正面还是负面

```
输入: "这部电影真好看!"
标签: 正面
```

**模型结构**:
```
输入: [CLS] 这部电影真好看! [SEP]
  ↓
BERT 编码器 (保留预训练权重)
  ↓
取 [CLS] 向量 (768维)
  ↓
分类头 (新增)
  ├─ Dropout
  └─ 全连接层 (768 → 2)
  ↓
输出概率:
  - 正面: 0.95  ← 预测结果
  - 负面: 0.05
```

**损失计算**:
```
真实标签: 正面 (1)
预测概率: 0.95
损失 = -log(0.95) = 0.05
```

**训练策略**:
- 冻结 BERT: 只训练分类头 (快速,适合数据少)
- 全部微调: BERT + 分类头都训练 (效果好,需要更多数据)
- LoRA 微调: 只训练少量参数 (高效,推荐)

---

### 任务2: 命名实体识别 (NER)

**应用场景**: 提取人名、地名、机构名等

#### 示例: 识别人名和地名

**任务**: 从句子中标注出实体类型

```
输入: "张三在北京工作"
输出:
  - 张三: 人名
  - 在:   O (无实体)
  - 北京: 地名
  - 工作: O
```

**模型结构**:
```
输入: [CLS] 张 三 在 北 京 工 作 [SEP]
  ↓
BERT 编码器
  ↓
每个词都有一个向量 (不只用 [CLS])
  ↓
每个词接一个分类头
  ↓
输出每个词的标签:
  - 张: B-PER (人名开始)
  - 三: I-PER (人名内部)
  - 在: O
  - 北: B-LOC (地名开始)
  - 京: I-LOC (地名内部)
  - 工: O
  - 作: O
```

**损失计算**:
```
对每个词位置分别计算损失,然后求平均
损失 = (损失_张 + 损失_三 + ... + 损失_作) / 7
```

### 任务3: 问答任务 (抽取式)

**应用场景**: 阅读理解、智能客服、文档检索等

#### 示例: 阅读理解

**任务**: 从文章中找出答案

```
问题: "姚明多高?"
文章: "姚明是中国著名篮球运动员,身高2.26米,曾效力于NBA火箭队。"
答案: "2.26米"
```

**模型结构**:
```
输入: [CLS] 姚明多高? [SEP] 姚明是...身高2.26米...火箭队。[SEP]
  ↓
分词后 (带位置编号):
位置: 0    1  2  3  4  5   6  7  8  ... 21 22 23 24 25 ...
词:  [CLS] 姚 明 多 高 ? [SEP] 姚 明 ... 2  .  2  6  米 ...
                                        ↑起始      ↑结束
  ↓
BERT 编码器
  ↓
每个位置的向量
  ↓
┌─────────────┴─────────────┐
↓                           ↓
起始位置分类器              结束位置分类器
(预测答案从哪开始)          (预测答案在哪结束)
  ↓                           ↓
位置21 "2" 得分最高         位置25 "米" 得分最高
  ↓                           ↓
└─────────────┬─────────────┘
              ↓
提取位置 21-25 的文本
              ↓
答案: "2.26米"
```

**损失计算**:
```
起始位置损失 = -log(P(位置21是起始))
结束位置损失 = -log(P(位置25是结束))
总损失 = (起始位置损失 + 结束位置损失) / 2
```

**特点**:
- ✅ 答案一定在文章中,不会编造
- ✅ 准确可靠
- ❌ 只能回答文章中有的内容
- ❌ 不能总结或推理

### 任务4: 句子对分类

**应用场景**: 文本相似度、文本蕴含、问答匹配等

#### 示例: 判断两个句子是否相似

**任务**: 判断两个句子的语义关系

```
句子A: "这部电影很好看"
句子B: "这个电影真不错"
标签: 相似 (1)

句子A: "这部电影很好看"
句子B: "今天天气很好"
标签: 不相似 (0)
```

**模型结构**:
```
输入: [CLS] 这部电影很好看 [SEP] 这个电影真不错 [SEP]
  ↓
BERT 编码器 (同时理解两个句子)
  ↓
取 [CLS] 向量
  ↓
分类头
  ↓
输出:
  - 相似:   0.92  ← 预测结果
  - 不相似: 0.08
```

### 任务5: 序列标注

**应用场景**: 词性标注、分词、语义角色标注等

#### 示例: 中文分词

**任务**: 标注每个字的分词位置

```
输入: "我爱北京天安门"
输出:
  - 我: B (词开始)
  - 爱: S (单字词)
  - 北: B
  - 京: E (词结束)
  - 天: B
  - 安: M (词中间)
  - 门: E
```

**模型结构**:
```
输入: [CLS] 我 爱 北 京 天 安 门 [SEP]
  ↓
BERT 编码器
  ↓
每个字的向量
  ↓
每个字接一个分类头 (4分类: B/M/E/S)
  ↓
输出每个字的标签
```

## 与生成式模型对比

### BERT vs GPT/Qwen

| 特性 | BERT | GPT/Qwen (因果模型) |
|------|------|---------------------|
| **架构** | 双向编码器 | 单向解码器 |
| **注意力** | 双向 (可看前后) | 单向 (只看前文) |
| **预训练任务** | MLM (填空) + NSP | CLM (预测下一词) |
| **擅长任务** | 理解类 (分类、抽取) | 生成类 (对话、续写) |
| **输入输出** | 固定长度输入 → 分类/标注 | 可变长度输入 → 生成文本 |
| **训练数据** | 无标注文本 (填空) | 无标注文本 (续写) |

### 数据整理器对比

```python
# BERT 分类/NER 任务
DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=True,  # 掩码语言模型
    mlm_probability=0.15  # 15% 的词被遮盖
)

# GPT/Qwen 生成任务 (您的代码)
DataCollatorForLanguageModeling(
    tokenizer=tokenizer,
    mlm=False  # 因果语言模型,不遮盖
)
```

### 任务选择指南

**选择 BERT 的场景**:
- ✅ 文本分类 (情感分析、主题分类)
- ✅ 信息抽取 (命名实体识别、关系抽取)
- ✅ 阅读理解 (从文章中找答案)
- ✅ 文本匹配 (相似度计算、检索)
- ✅ 需要准确性,不能编造信息

**选择 GPT/Qwen 的场景**:
- ✅ 文本生成 (对话、续写、创作)
- ✅ 机器翻译
- ✅ 文本摘要
- ✅ 代码生成
- ✅ 需要灵活性和创造性

## 实战技巧

### 1. 选择合适的预训练模型

```
中文任务:
- bert-base-chinese (Google)
- chinese-bert-wwm (哈工大)
- roberta-wwm-ext-large (哈工大)

英文任务:
- bert-base-uncased
- bert-large-uncased
- roberta-base

多语言:
- bert-base-multilingual-cased
```

### 2. 微调策略

```
数据量少 (< 1000 样本):
→ 冻结 BERT,只训练任务头

数据量中等 (1000-10000):
→ LoRA 微调 (推荐,高效)

数据量大 (> 10000):
→ 全部微调 (效果最好)
```

### 3. 超参数建议

```
学习率: 2e-5 到 5e-5
批次大小: 16 或 32
训练轮数: 3-5 轮
最大长度: 128 或 512
Warmup 比例: 0.1
```

### 4. LoRA 配置 (参考您的代码)

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,  # 秩,越大效果越好但参数越多
    lora_alpha=16,
    target_modules=['query', 'key', 'value'],  # BERT 的注意力层
    lora_dropout=0.1,
    bias='none',
    task_type='SEQ_CLS'  # 或 'TOKEN_CLS', 'QUESTION_ANS'
)

model = get_peft_model(bert_model, lora_config)
```

## 总结

### BERT 的核心优势
1. 🎯 **双向理解** - 同时看前后文,理解更准确
2. 🎯 **预训练强大** - 在海量数据上学到通用知识
3. 🎯 **迁移学习** - 换个头就能做各种任务
4. 🎯 **效果稳定** - 不会编造信息,结果可靠

### BERT 的局限
1. ❌ **不擅长生成** - 架构决定了只能做理解任务
2. ❌ **固定长度** - 输入长度有限制 (512 tokens)
3. ❌ **计算量大** - 双向注意力计算复杂

### 最佳实践
- 理解任务用 BERT,生成任务用 GPT/Qwen
- 优先使用 LoRA 微调,省时省力
- 根据数据量选择合适的微调策略
- 注意任务头的设计,不同任务用不同的头
