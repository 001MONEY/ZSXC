# 蔬菜分类模型训练过程总结

> 项目：基于 YOLOv5-cls 的 6 类蔬菜图像分类
> 数据集：自采增强数据（白底）+ Kaggle 真实照片（微调）
> 日期：2026-08-03 ~ 2026-08-04

---

## 1. 项目概述

- **任务**：6 类蔬菜图像分类
- **类别**：`beans`(豆角)、`eggplant`(茄子)、`ladies_finger`(秋葵)、`onion`(洋葱)、`pointed_gourd`(蛇瓜)、`potato`(土豆)
- **框架**：YOLOv5-7.0（`classify/train.py`）
- **模型**：`yolov5s-cls.pt`（预训练，417 万参数，10.4 GFLOPs）
- **环境**：Python 3.11，PyTorch 2.5.1+cu121，RTX 3060 Laptop GPU (6GB)

## 3. 训练过程

脚本：`train_cls.py`（封装 `classify/train.py`，默认 batch 64 → 后改 32）

### 3.1 四次训练记录

| 实验     | 数据  | epochs | batch | 结果              | 说明                    |
| ------ | --- | ------ | ----- | --------------- | --------------------- |
| `veg`  | 白底  | 30     | 64    | 中断，无权重          | 第一次运行中断               |
| `veg2` | 白底  | 30     | 64    | 中断于 epoch 14    | 中断，有部分权重              |
| `veg3` | 白底  | 30     | 64    | ✅ **top1=100%** | 完整训练，`best.pt` 可用     |
| `veg4` | 白底  | 100    | 32    | top1=99.6%      | **后期过拟合**，best 在第 8 轮 |

### 3.2 关键发现：过拟合（veg4）

100 轮训练中：

- 第 8 轮 top1 已达 **100%**（`best.pt` 保存在第 8 轮）
- epoch 35 起 **val_loss 从 0.422 一路涨到 0.464**，train_loss 停在 0.421 → 典型过拟合
- 结论：**30 轮足够，甚至 10 轮内已收敛**；此数据集简单（白底单物体），多训无益

### 3.3 微调方案（已在服务器执行）

目标：解决真实场景泛化差的问题

```bash
python train_cls.py --data yolov5cls_finetune \
    --model veg3/best.pt \        # 从已训练模型继续（保留知识）
    --epochs 50 --batch 32 --lr0 0.0001 --name ft
```

关键参数：

- `--model` 用 `veg3/best.pt` 而非预训练权重 → 真正的**微调**
- `--lr0 0.0001` 小学习率，防止破坏已学特征

### 3.4 服务器微调结果 ✅

| 项目      | 结果                          |
| ------- | --------------------------- |
| 训练环境    | 服务器 GPU（本地 CPU 太慢，改为服务器训练）  |
| 训练轮数    | 100 轮                       |
| best 位置 | **第 5 轮**，top1 = **99.94%** |
| 输出模型    | `best.pt`（8.08MB，已传回本地）     |

**训练时间**：服务器上约 100 轮，速度远快于本地。

## 4. 推理测试

脚本：`predict_cls.py`（封装 `classify/predict.py`）

### 4.1 白底增强图测试（inference_test）

- 12 张（每类 2 张），**12/12 全部正确**，置信度 0.91~0.92
- 单张推理 **3.5ms**（GPU），约 285 FPS
- 类别间无混淆（错误类置信度仅 0.02）

### 4.2 真实复杂环境测试（real_test）⚠️ 关键问题

从 Kaggle 随机挑 18 张真实照片（豆类/茄子/土豆 12 张 + 卷心菜/番茄/胡萝卜 6 张）：

| 指标     | 白底图  | 真实照片          |
| ------ | ---- | ------------- |
| 对应类准确率 | 100% | **25%（3/12）** |
| 平均置信度  | 0.91 | 0.4~0.6       |

**结论：模型严重过拟合到白底训练域**（域偏移）。错误示例：土豆 0.96 判成茄子、番茄 0.95 判成茄子、卷心菜 0.92 判成蛇瓜。

### 4.3 微调后模型真实场景测试（server_ft）✅ 泛化提升

用服务器微调模型（`best_windows.pt`）重测同样的 18 张真实照片：

| 真实类别       | 张数     | 正确数    | 准确率      | 置信度范围         |
| ---------- | ------ | ------ | -------- | ------------- |
| 豆类 Bean    | 4      | 4      | 100%     | 0.75~0.93     |
| 茄子 Brinjal | 4      | 4      | 100%     | 0.90~0.94     |
| 土豆 Potato  | 4      | 4      | 100%     | 0.91~0.96     |
| **对应类合计**  | **12** | **12** | **100%** | **0.75~0.96** |

**微调前后对比（同一批真实照片）：**

| 指标     | 微调前（veg3）     | 微调后（服务器模型）        |
| ------ | ------------- | ----------------- |
| 对应类准确率 | **25%（3/12）** | **100%（12/12）**   |
| 平均置信度  | 0.4~0.6（犹豫）   | **0.75~0.96（自信）** |
| 错误模式   | 乱猜（蛇瓜/秋葵）     | 无                 |

> 非对应类（卷心菜/胡萝卜/番茄）仍预测错误属**正常现象**——模型只有 6 个类别，未见过这些类，属于"未知类别"场景。

## 5. 过程中修复的问题

### 5.1 标注文字白底白字看不见

- 原因：`classify/predict.py` 写死 `txt_color=(255,255,255)`，且 `Annotator.text` 不画背景
- 修复：先画黑色背景框再写白字（已改 `classify/predict.py`）

```python
bbox = annotator.font.getbbox(text)
tw, th = bbox[2] - bbox[0], bbox[3] - bbox[1]
annotator.draw.rectangle((26, 26, 26 + tw + 14, 26 + th + 14), fill=(0, 0, 0))
annotator.text((32, 32), text, txt_color=(255, 255, 255))
```

### 5.2 训练误判为 CPU

- 现象：误以为训练跑在 CPU
- 真相：`nvidia-smi` 显示训练进程 (PID 18940) 在用 GPU（47%，2.6GB）
- 原因：8 个 dataloader worker 占满 CPU 造成的错觉

### 5.3 Linux 训练的 .pt 在 Windows 无法加载

- 现象：`torch.load` 报 `NotImplementedError: cannot instantiate 'PosixPath'`
- 原因：Linux 服务器保存的 checkpoint 里有 `PosixPath` 对象，Windows 无法实例化
- 解决：脚本 `fix_linux_pt.py` —— 打补丁 `PosixPath → WindowsPath` 重新保存

```python
_temp = pathlib.PosixPath
pathlib.PosixPath = pathlib.WindowsPath
ckpt = torch.load(src, map_location='cpu')
torch.save(ckpt, dst)
pathlib.PosixPath = _temp
```

## 8. 结论与后续

### 结论

1. 白底数据上模型表现优秀（top1 100%），但**泛化到真实场景差**（仅 25%）
2. 根本原因：训练数据单一（白底、单物体、固定光照），域偏移严重
3. 100 轮无必要，10~30 轮即可收敛（白底数据）
4. **混合真实照片微调是解决域偏移的有效方案**：真实场景准确率 25% → **100%**

### 后续建议

- [x] 服务器上用混合数据（白底+真实）微调（已完成，top1 99.94%）
- [x] 微调后重测 18 张真实照片（对应类 12/12 = 100%）
- [ ] 用微调后模型（`best_windows.pt`）导出 ONNX 部署
- [ ] 若需支持更多类别：收集卷心菜/番茄/胡萝卜等新类数据，扩展类别数
- [ ] 可选：增加真实数据量 / 背景合成增强 / 多尺度裁剪 进一步提升
