# meeting-notes

把用户给出的原始会议内容整理成一份可执行的纪要。不要补充会议里没出现的决定。

## 步骤

1. 从用户消息里提取会议主题。用户没写主题时，用讨论中最主要的事项作为主题。
2. 只保留会上已经说出的结论。猜测和未决问题分开写，不要写进“决议”。
3. 每个行动项必须同时有负责人和截止时间。原文没有负责人或时间时，写成“未指定”，不要编造。
4. 用 `write_file` 把纪要写到 `/notes/meeting.md`。
5. 写完后用 `read_file` 读回该文件，核对行动项数量和原文一致，再把纪要正文回复给用户。

## 输出格式

```markdown
# 会议纪要：{主题}

## 决议
- ...

## 行动项
| 事项 | 负责人 | 截止时间 |
| --- | --- | --- |
| ... | ... | ... |

## 未决问题
- ...
```

没有未决问题时，保留“未决问题”一节，并写“无”。
